What is collected, and why

Strictly necessary

The site is a set of static files. Serving a page requires your network address, the page requested, and your browser's user agent string. This is ordinary web-server operation and happens whether or not you accept analytics. This site is hosted on GitHub Pages, so these access records are handled by GitHub under their own privacy terms.

Analytics, only after you accept

If you accept, two services are loaded:

  • Google Analytics 4 records which pages are viewed, the referring site, a coarse device and browser category, and an approximate area-level location derived from your network address.
  • Microsoft Clarity records a short session recording. This includes pointer movement, clicks, and which parts of a page are actually read. Clarity collects more detail than page-view analytics, which is why it is opt-in rather than automatic. It is loaded on six pages only: the Agent Briefing game, the Build Maker, the Builds hub, the Server Status page, and the two Diablo 4 timer pages. Those are the pages with a custom interface where a visitor can get stuck. Guide, lore, video and index pages never load it, so no session recording exists for them.

Both are used to understand which guides are useful and which pages are broken. They are not used for advertising and are not shared for advertising purposes. If you would rather we collected nothing at all, declining is a complete answer.

Outbound link tracking, only after you accept

When you accept analytics and then click a link that leaves this site, the destination domain is recorded as an analytics event. Clicks on YouTube, Instagram, Discord, and similar destinations are labelled separately. Nothing is recorded if analytics are declined.

Stored on your own device

These values never leave your browser, are not sent to us, and contain no personal detail:

  • your analytics choice, so the dialog is not shown again;
  • a record of that choice with a timestamp and the policy version in force, kept for proof that consent was given;
  • progress in the Agent Briefing mini-game, so solved days stay solved;
  • a short-lived flag that stops a loot panel refreshing twice on the same visit.

You can erase all of it at any time by clearing site data for this domain in your browser.

Video thumbnails

Thumbnails are normally stored on this site's own server and served from here. If a local thumbnail is missing, the page may request a fallback image from i.ytimg.com (Google/YouTube). A short appears on YouTube only if you press play. The player itself uses YouTube's privacy-enhanced domain, which is designed not to set tracking cookies until you interact with it.

Comment threads

Each page offers a button that loads the comment thread. Nothing is requested until you press it. The thread is served by Giscus from giscus.app and stored in GitHub Discussions, so a comment you write is public and is handled under GitHub's privacy terms. Loading the thread also means GitHub and Giscus can see the request. No thread is loaded automatically.

Discord widget

On the Discord page, the server widget is not loaded until you press "Load Discord widget". If you load it, Discord may see your request and set storage on its own domain.

The feedback form

If you send feedback, you choose to give a name, an email address, an optional related page URL, and a message. That form is delivered through Web3Forms, a third-party form relay, which passes your message to the address configured for this site. The message is then delivered to our email provider, Google Gmail, and is used only to reply to you or to act on the feedback. It is not used for marketing. Please do not send anything sensitive.

How long data is kept

  • Analytics event data is deleted after 2 months. This is the retention window configured in the analytics account, and it is shorter than the service default of 14 months.
  • Analytics user-level data is deleted after 2 months as well, with the "reset on new activity" option enabled. That means a visitor who keeps returning has their identifier window refreshed each time, so an identifier for a regularly active visitor can persist longer than two months. Turning this option off would make the window absolute; it is left on because it reduces the amount of data tied to a single person over time.
  • Clarity data: playback recordings are retained for up to 30 days; a small sampled set, favorites, and heatmap data can be retained for up to 9 months in Microsoft Clarity. Declining analytics means Clarity is never loaded at all.
  • Server request logs follow GitHub Pages' published retention policy.
  • Feedback is kept for up to 12 months, or 30 days after the issue is resolved, whichever is shorter, and is then deleted from our mailboxes. You can ask us to delete it sooner.
  • Consent records on your device stay until you clear them.
